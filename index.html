Сколько на самом деле даёт выбор языковой модели под запрос

Исследование для ВКР · 2026 · Python, pandas, NumPy, бутстреп

Компании ставят у себя несколько языковых моделей и хотят отправлять простой запрос в дешёвую, а сложный — в сильную. Выгоду такой схемы обычно оценивают через «оракула»: для каждого запроса берут модель с лучшей оценкой. Я проверил, можно ли этой оценке доверять, когда качество ответов оценивают люди.

Что сделал
  • Подготовил к анализу датасет POLLUX от Сбера: 161 076 строк экспертных оценок по 2 115 русскоязычным запросам. Привёл шкалы от 0–1 до 0–4 к одной, отделил флаги поломки ответа от оценок, сравнивал модели только по общим критериям.
  • Разделил экспертов на две независимые половины: модель выбирается по одной, качество выбора проверяется по другой. Доверительные интервалы — бутстрепом.
  • Проверил отраслевую часть на нефтегазовом бенчмарке FormationEval: 505 вопросов, 72 модели.
Результат
  • 61–73 % «выигрыша» оракула — шум экспертной разметки, а не разница между моделями. Реальный запас — около 0.02 по шкале 0–1, и он статистически отличен от нуля.
  • Простой выбор модели по типу задачи забирает только треть этого запаса.
  • В нефтегазовых вопросах выбор модели ничего не меняет в 78.8 % случаев в петрофизике и в 91.7 % — в нефтегазовой геологии.
  • Готовлю статью и доклад на научную конференцию МФТИ, весна 2027.

Квазар — голосовой ассистент, который работает на ноутбуке без интернета

Личный проект · 2026 · Python, PyTorch, GigaAM, Silero, Ollama + Qwen3, SQLite, pytest

Ассистент для Windows слушает микрофон, откликается на имя и выполняет команды на компьютере. Простые команды разбирают правила за миллисекунды. Сложные уходят локальной языковой модели, которая сама выбирает инструменты.

1 · слухwake word + VAD
2 · речь в текстGigaAM-v3, 0.5–0.9 с на CPU
3 · роутерправила или LLM-агент
4 · защитаsafe / confirm / deny
5 · действие55 инструментов, журнал
Что сделал
  • Собрал конвейер распознавания и синтеза речи на открытых моделях: GigaAM-v3 от Сбера и Silero.
  • Написал роутер: правила для частых команд, локальная Qwen3 через Ollama для остальных, облачная модель — по запросу.
  • Сделал слой безопасности: у каждого инструмента свой уровень риска, опасные действия выполняются только после голосового «да».
  • Покрыл код 97 автотестами, включая эталонный набор из 30 фраз для проверки роутера.
Результат
4–7 → 16–17токенов в секунду у локальной модели на RTX 3050 с 4 ГБ
67 → 73 %доля модели на видеокарте после квантования KV-кэша и flash attention
8.8 схолодный старт голосового режима при норме 20 с

Честное ограничение: на 4 ГБ видеопамяти ответ на сложную задачу занимает 5–32 с, по ТЗ нужно 3 с до начала ответа. На видеокарте с 8 ГБ ожидаю в несколько раз быстрее.
